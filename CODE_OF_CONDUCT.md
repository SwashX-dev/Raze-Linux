# Code of Conduct

Raze Linux follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and focus criticism
on code and ideas, not people. Harassment and discrimination are not tolerated.

Report unacceptable behaviour by opening a private security advisory on the
repository or contacting the maintainer through GitHub (@SwashX-dev). Reports are
handled confidentially.
