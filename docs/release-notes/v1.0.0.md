# Raze Linux 1.0.0

**Rust-Powered. Performance-Driven. Minimal by Design.**

First release of Raze Linux: a NixOS-derived, Nix-built x86_64 distribution with
Rust-first system components, a keyboard-first desktop, sudo-rs, and a graphical
installer.

## Highlights

- **Linux 7.3.1**, the latest stable kernel at release.
- **r6**: Rust init + single-process service supervisor. Verified as PID 1 in the
  Raze Core image on every CI run; matches s6's activation latency (32.3 vs
  32.4 ms median for 20 services) with 2 processes instead of 27.
- **Rix**: Rust package-management CLI with native, bit-for-bit Nix-compatible NAR
  hashing and store verification, generations/rollback and instant search; installs
  and builds are delegated to Nix and printed as such.
- **sudo-rs** is the only sudo.
- **Desktop**: niri with the Raze session (waybar, fuzzel, foot, mako); a
  software-rendered sway session starts automatically on machines/VMs without a
  3D-capable GPU.
- **Installer**: Calamares with Raze branding; writes a flake-based `/etc/nixos`
  pinned to the same sources as the ISO.
- **Lean defaults**: dbus-broker, zram, no speech-dispatcher, small font set.

## Validation performed for this release

- r6: 14 unit + 18 end-to-end tests; Raze Core boot test (r6 PID 1, service restart,
  DHCP, logs, poweroff) — locally and on GitHub Actions.
- Rix: 16 tests incl. NAR hashes compared with `nix hash path`.
- Desktop VM test (NixOS test driver): sudo-rs authentication, branding,
  dbus-broker, zram, NetworkManager, greetd autologin, software fallback session,
  waybar, rix hash/verify vs Nix — locally and on GitHub Actions.
- Full graphical installation in QEMU/KVM (UEFI, virgl): live boot, Calamares
  (language, keyboard, erase disk, desktop, profile, user), install, boot from disk
  without the ISO, login, terminal, network, `rix install hello`, sudo-rs, reboot,
  persistence.

## Not in this release (see Known limitations)

- Rift compositor (niri is the default).
- r6 as the default PID 1 of installed systems (systemd is; r6 has an
  experimental, not boot-tested entry).
- A native Nix evaluator.
- Tested support for BIOS installs, manual partitioning, dual boot, non-default
  desktops and real hardware.
