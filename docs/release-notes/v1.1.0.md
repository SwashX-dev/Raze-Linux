# Raze Linux 1.1.0

**Rift Desktop, Rift Shell, and r6 everywhere.**

## Download

| File | |
|---|---|
| `raze-linux-v1.1.0-x86_64.iso` | Live system (r6, Rift) + Calamares installer (UEFI/BIOS hybrid ISO) |
| `SHA256SUMS` | `sha256sum -c SHA256SUMS` |

The ISO is not signed (no signing key exists yet); verify the checksum.
Upgrading a 1.0 installation: [docs/installation/upgrade.md](../installation/upgrade.md).

## Highlights

- **r6 is PID 1 and the service manager everywhere**: the live ISO, installed systems
  and the desktop session (`r6-user`). systemd only runs inside the initramfs.
  Replacements: eudev, elogind, dbus-daemon, ntpd-rs, `r6-tmpfiles`, `r6-syslogd`, an
  r6 switch-to-configuration (`nixos-rebuild switch` works), periodic services
  instead of timers. New r6 features: ambient capabilities, umask, rlimits, OOM score,
  runtime/state directories, user supervisor, setenv/import-env, kmsg logging, syslog,
  a build-time warning for NixOS services without an r6 equivalent.
- **Rift**, Raze's own Wayland compositor (Rust, Smithay): scrollable tiling,
  dynamic workspaces per monitor, animations, GLES and pixman renderers (works
  without 3D acceleration), ext-image-copy-capture and wlr-screencopy, XWayland,
  session lock, idle notify, foreign toplevel list, data control, fractional
  scaling, night light, JSON IPC. No systemd libraries linked.
- **Rift Shell** (Quickshell): panel, launcher, control centre, notification daemon
  with history and Do Not Disturb, lock screen, power menu, screenshots, screen
  recording, clipboard history, media controls, OSD, polkit agent, idle lock,
  themes, settings import/export, plugins, multi-monitor.
- **Installer**: Rift + Rift Shell, r6, the performance kernel profile and sudo-rs by
  default; GRUB on EFI too (no systemd-boot).
- **fastfetch** recognises Raze (hexagon-R logo, init, WM); `neofetch` runs it.
- os-release reports the Raze version (`PRETTY_NAME="Raze Linux 1.1.0"`).

## Benchmarks

All measured in QEMU/KVM; method and raw data in
[docs/performance](../performance/benchmarks.md).

| | Raze 1.1 | Compared with |
|---|---|---|
| Kernel start → login screen (same desktop system) | **5.08 s** with r6 | 6.41 s with systemd |
| System memory used at the login screen | **355 MB** with r6 | 379 MB with systemd |
| Userspace PSS at the login screen | 93.5 MB with r6 | **73.0 MB** with systemd (socket-activated nix-daemon) |
| r6 vs s6: PID 1 → 20 services | 32.9 ms | **31.6 ms** (equal within noise); r6 runs 2 processes vs 27 |
| Compositor idle CPU per minute | **0.00 s** Rift | 0.05 s niri |
| Desktop session memory (PSS) | **217 MB** Rift + Rift Shell | 244 MB niri + waybar |

Fixes found by measuring: r6-init now flushes the activation's writes to
`/etc/passwd`/`/etc/shadow` at startup (a power loss in the first ~30 s of boot could
lose them); udisks2/upower/rtkit are started on demand; Rift starts Xwayland on the
first X client; Rift Shell creates overlays on demand and uses Qt's software
renderer (session 352 → 217 MB).

## Validation performed for this release

- **Rust**: rustfmt and Clippy (`-D warnings`) clean for r6, rix, Rift and the
  rift-shell helper; r6 22 unit + 21 end-to-end tests, rix 17, Rift 15 (layout,
  configuration, night light).
- **VM tests** (NixOS test driver; the driver's backdoor runs as an r6 service):
  `desktop` (r6 PID 1, no systemd process, every service up, firewall rules,
  sched_ext with the performance profile, D-Bus activation, syslog, read-only
  `r6 status` for users, sudo-rs, fastfetch, NetworkManager, ntpd-rs, Rift on pixman +
  Rift Shell, windows over IPC, grim, wf-recorder, notifications, session lock,
  switch-to-configuration, rix hashing), `desktop-systemd` (same desktop with
  `raze.init = "systemd"`), `core-boot` (Raze Core, r6 PID 1).
- **Live ISO** (QEMU/KVM, UEFI, no 3D): boots with r6 as PID 1 and no systemd process,
  Rift + Rift Shell autologin, installer starts automatically.
- **Graphical installation** of the release ISO (UEFI, empty 30 GB disk, erase disk,
  Raze Desktop, default profile): Calamares under r6 (kpmcore partitioning),
  installation in about 5½ minutes, "Restart now" reboots into GRUB on the disk,
  login, Rift, fastfetch (Raze Linux 1.1.0, r6-init, rift), terminal.
- **Installed desktop** (VM): r6 PID 1, login via greetd/PAM, Rift on DRM with pixman
  (no 3D) and with GLES (virgl), keyboard and pointer input, launcher, screenshots,
  clipboard history, notifications, volume keys with OSD, PipeWire, lock/unlock via
  PAM (wrong password rejected), suspend (s2idle) and resume, log out, restart, shut
  down, `rix install hello`, live `switch-to-configuration` (add/change/remove
  services) and rollback. Floating dialogs: GTK dialog in headless Rift.
- **Upgrade from 1.0.0**: the published 1.0.0 ISO (checksum verified), its installer's
  configuration, then `docs/installation/upgrade.md` step by step: r6 PID 1 after the
  reboot, all services up; live switch to Rift (`rix system switch`); rollback to the
  1.0 generation boots systemd 1.0 again.
- **Benchmarks** as above (r6 vs systemd, r6 vs s6, Rift vs niri).

Not validated: real hardware, BIOS installs, manual partitioning, dual boot, desktops
other than Rift and niri.

## Changes since 1.0.0

- Default desktop: Rift + Rift Shell (was niri + waybar). niri and the other
  desktops remain selectable.
- Default PID 1: r6 (was systemd; r6 was an experimental boot entry).
  `raze.r6.bootEntry.enable` has no effect (warning).
- EFI installs use GRUB.
- Screen recording uses wf-recorder.
