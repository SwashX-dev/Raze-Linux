**Rift Desktop, Rift Shell, and r6 everywhere.**

## Highlights

- **r6 is PID 1 and the service manager everywhere**: the live ISO, installed systems
  and the desktop session (`r6-user`). systemd only runs inside the initramfs.
  Replacements: eudev, elogind, dbus-daemon, ntpd-rs, `r6-tmpfiles`, `r6-syslogd`, an
  r6 switch-to-configuration (`nixos-rebuild switch` works), periodic services
  instead of timers. New r6 features: ambient capabilities, umask, rlimits, OOM score,
  runtime/state directories, user supervisor, setenv/import-env, kmsg logging, syslog,
  a build-time warning for NixOS services without an r6 equivalent.
- **Rift**, Raze's own Wayland compositor (Rust, Smithay): scrollable tiling,
  dynamic workspaces per monitor, animations, GLES and pixman renderers (works
  without 3D acceleration), ext-image-copy-capture and wlr-screencopy, XWayland,
  session lock, idle notify, foreign toplevel list, data control, fractional
  scaling, night light, JSON IPC. No systemd libraries linked.
- **Rift Shell** (Quickshell): panel, launcher, control centre, notification daemon
  with history and Do Not Disturb, lock screen, power menu, screenshots, screen
  recording, clipboard history, media controls, OSD, polkit agent, idle lock,
  themes, settings import/export, plugins, multi-monitor.
- **Installer**: Rift + Rift Shell, r6, the performance kernel profile and sudo-rs by
  default; GRUB on EFI too (no systemd-boot).
- **fastfetch** recognises Raze (hexagon-R logo, init, WM); `neofetch` runs it.
- os-release reports the Raze version (`PRETTY_NAME="Raze Linux 1.1.0"`).

## Changes since 1.0.0

- Default desktop: Rift + Rift Shell (was niri + waybar). niri and the other
  desktops remain selectable.
- Default PID 1: r6 (was systemd; r6 was an experimental boot entry).
  `raze.r6.bootEntry.enable` has no effect (warning).
- EFI installs use GRUB.
- Screen recording uses wf-recorder.
